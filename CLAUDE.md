# TwitchAdSolutions

Twitch ad-blocking scripts that run in the twitch.tv page, loaded either by a userscript manager (Violentmonkey, Tampermonkey, Userscripts for Safari; Greasemonkey is incompatible) or as a uBlock Origin `userResourcesLocation` scriptlet (`twitch.tv##+js(twitch-videoad)`). They hook `window.fetch` and Twitch's video Web Worker, detect ad segments in HLS m3u8 playlists, and either swap to an ad-free backup stream (other player types) or strip the ad segments. Fork of ryanbr/TwitchAdSolutions (originally pixeltris, archived); GitHub `xBandaku/TwitchAdSolutions`.

## Stack

- Plain browser JavaScript (ES2022), no build step, no bundler. Each script file is shipped exactly as committed; install/update URLs point at `raw/master`.
- Dev tooling only: Node 22/24, npm, ESLint 10 (+ `eslint-suppressions.json` baseline), Playwright 1.64 (Chromium/Firefox/WebKit), acorn (AST checks), Python 3 (Discord notify script + `test:package`).

## Worker blob serialization (critical)

Functions serialized with `.toString()` into the worker blob cannot reference outer-scope variables: `processM3U8`, `stripAdSegments`, `resolvePlaylistUrls`, `hookWorkerFetch`, `getAccessToken`, `gqlRequest`, `hasAdTags`, `getMatchedAdSignifiers`, `notifyAdComplete`, `getStreamUrlForResolution`, `parseAttributes`, `getServerTimeFromM3u8`, `replaceServerTimeInM3u8`, `pruneStreamInfos`, `createStreamInfo`, `getWasmWorkerJs`, `videoCodecFamily`, `resetAdEndTracking`, `triggerEarlyReloadIfNeeded`, `getBackupSequenceOffset`, `shiftMediaSequence`, `planUntrackedAdReload`.
- Declare state in `declareOptions()` (also serialized) or the inline blob template literal.
- Pass window values in after `declareOptions(self)`, e.g. `ReloadPlayerAfterAd = ${ReloadPlayerAfterAd};`.
- Hoisting a regex or referencing an outer variable from these functions throws `ReferenceError` only at runtime in the worker (v68.5.42 fixed one in video-swap-new's `gqlRequest`).
- `createStreamInfo()` declares every StreamInfo field up front (70 vaft, 31 video-swap-new).

## Conventions

- Synced pairs carry identical logic. Tests require each userscript/uBlock pair to match statement for statement at top level. uBlock files start with the line `twitch-videoad.js text/javascript` (resource header, not JS); tooling strips it.
- Version bump for any functional change: `@version` and `ourTwitchAdSolutionsVersion` together, in every format of that script. Tests require vaft and video-swap-new to report one version in `@version`, diagnostics and the settings panel. Current: vaft 68.5.49/134, video-swap-new 1.98/66, strip 1.13/30, Brave helper 1.3.6/10.
- Naming differs per script: vaft `AdSignifiers`, `AdSegmentURLPatterns`, `ForceAccessTokenPlayerType`, `ReloadPlayerAfterAd`; video-swap-new `AD_SIGNIFIERS`, `AD_SEGMENT_URL_PATTERNS`, `OPT_FORCE_ACCESS_TOKEN_PLAYER_TYPE`, `ReloadPlayerAfterAd`; strip `ForceAccessTokenPlayerType` (default `site`), `ReloadPlayerAfterAds`.
- Logging (vaft): `[AD DEBUG]` lines go through `tasLog()`, which calls `console.log` and keeps the line for the bug report. `tasLog` is serialized into the worker blob; in the worker it posts `{ key: 'TASLog', text }` and the page's worker listener stores it with `recordTASLog` (150 lines, 400 chars each). `redactTASLog` hides channel names, URLs and tokens when the report or export is built, never at capture. New vaft logs should use `tasLog`; the nested-frame, clip-editor and duplicate-script exits still call `console.log`. video-swap-new and strip call `console.log` directly. Many logs are deduped per break or per page load.
- Settings: `localStorage` keys `twitchAdSolutions_<name>`, read once at init and injected into the worker. User-facing ones are in README; vaft-only toggles include `backupSwapFirst`, `preferLowQualityBackup`, `fastAutoplayFirstTry`, `recoverFromSilentMute`, `disableAdSpoofing` (default `'true'` = spoofing off), `disablePostBreakWedge`, `pageRefreshFallback`, `iosSoftReload` (default on), `alignBackupSequence`, `keepBackupSessions`, `untrackedReload`, `unhookedPageReload`, `disableReloadCap`, `driftCorrectionRate` (1.1). `earlyReloadPollThreshold` defaults to 3 in vaft and 5 in video-swap-new. README's settings table lists only some keys.
- Backup player types: vaft `embed`, `site`, `popout`, `mobile_web`; video-swap-new `embed`, `popout`, `mobile_web`. `autoplay` (360p) is only a last-resort/fast-path backup in vaft and is never pinned.
- Overlay hiding: only exact attribute selectors with no parent walking (currently `[data-test-selector="sda-wrapper"]`). Broader hides (`.player-overlay-background`, ad-break text match) were removed for hiding real UI.
- Changelog entries are prose paragraphs that end with an evidence classification, validation done, and the version line.

## Evidence rules (findings, changelog, PRs)

- Label every playback finding `confirmed live`, `reproduced from a captured response`, or `synthetic edge case` (PR template adds `repository-only change`). Synthetic-only fixes are "preventive hardening". Say what evidence is missing and whether the failing path actually ran.
- Run `test:captured` first. Never modify a captured response to manufacture a trigger; put mutations in synthetic tests. When refreshing captures, review redactions; never store raw token responses or private headers.
- For each regression, show it fails before the fix for the expected reason and passes after (`test:regression` or equivalent recorded commands).

## vaft behaviour worth knowing

- SSAI ads live in m3u8 segments and can be stripped. CSAI ads come from `edge.ads.twitch.tv`, are only logged, and must not trigger reloads: when `hadStrippedSegments === false`, skip the reload to avoid cascades.
- Buffer monitor (`monitorPlayerBuffering`) polls every 1-3 s and drives pause/play or reload. Reload cooldown 30 s, escalates to 90 s after 3+ reloads in 5 min; one buffer-monitor reload per recovery window (`recoveryReloadUsed`); grace 15 s after reload, 10 s after backup switch.
- While the page is hidden, `doTwitchPlayerTask` defers reloads and pause/play to the next `visibilitychange` (`deferTwitchPlayerTask`): in hidden Chrome tabs Twitch leaves a restarted live player `Idle` until focus (#74, confirmed live). A deferred task is dropped if an ad break is active on return. The post-break wedge check skips hidden pages outside PiP, because Chrome stops decoding frames there.
- Reload kinds `early`, `untracked-ads` (both from the worker) and `worker-recovery` (main thread) request a fresh player and token and bypass the near-live latency check; other reloads are soft. Apple touch devices keep the player and only refresh the token. So does a recovery attempt that starts after the tab became hidden mid-recovery (issue 74).
- Backup handling: committed backups are renumbered onto the native media sequence (`AlignBackupSequence`); ad-laden backup sessions are kept up to 60 s of ads (`KeepBackupSessions`); while every backup type is ad-laden (`AllBackupsAdLaden`) the active type is kept and poll/loading-circle early reloads are skipped.
- Early reload fires on prolonged all-stripped freezes (3 polls, or 1 when the recovery cache has <3 segments). Recovery-segment cache is dropped once older than 30 s (`RecoverySegmentsAt`).
- Sticky CSAI fast path keeps its own early-reload trigger because the normal-path check is unreachable after its early return.
- `startDriftCorrection` runs 1.1x with a 30 s safety timeout; `playerForMonitoringBuffering = null` on reload forces re-acquisition.
- Right after a reload the backup probe starts at the top of the reordered list (pinned type first); a single-probe pick that still has ads is not pinned.

## Gotchas

- Editing one file of a synced pair without the other fails `npm test`. Adding/removing a shipped script means updating `tests/scripts.js` (lint, packaging and sync tests all read it).
- `test:package` fails on hosts with only the Windows Store `python` alias.
- Release is `workflow_dispatch` on `release.yml` with `dry_run` defaulting to true. Jobs: `build` (read-only, runs all checks), `publish` (write, skipped on dry run), `announce`; actions pinned to commit SHAs. It reads the version from `vaft/vaft.user.js` (`x.y.z` only) and notes from the matching or `Unreleased` CHANGELOG section.
- Twitch's player reacts badly to mixed m3u8 sources (freezes, repeats, desync); many recovery paths exist only to undo that. Change timing constants with care.
